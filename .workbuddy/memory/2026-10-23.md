## 修复 Gradle wrapper 发行版下载超时（SocketTimeoutException）

- 现象：`gradlew` 下载 gradle-9.4.1-bin.zip 报 `Read timed out`，dists 缓存残留 0 字节 `.part` 文件
- 根因：Gradle(JVM) 不认系统代理/环境变量代理，裸连 services.gradle.org（307 跳 GitHub Releases）国内直连 10 秒超时；本机 Clash 在 127.0.0.1:7890
- 排查：腾讯/华为镜像均未同步 9.4.1（sha256 404），换镜像不可行；阿里云 maven 镜像有 AGP 9.2.1（备用有效）
- 修复：
  1. 经 Clash 8 线程分段下载官方 zip（137,878,901 字节），SHA256 与 wrapper 期望值一致，预置到 `C:/Users/AI/.gradle/wrapper/dists/gradle-9.4.1-bin/arn2x92ynaizyzdaamcbpbhtj/`，清除 0 字节 `.part`/`.lck`
  2. 新建 `C:/Users/AI/.gradle/gradle.properties` 配置代理指向 127.0.0.1:7890
- 验证：`gradlew --version` 输出 Gradle 9.4.1；`gradlew help` BUILD SUCCESSFUL（4m46s，插件经代理下载成功）
